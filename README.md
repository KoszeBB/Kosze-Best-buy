# Gdzie kupić Best Buy – mapa sklepów

Strona z mapą sklepów, w których stoją czerwone kosze Best Buy.

- `index.html` – strona
- `style.css` – wygląd (kolory #dc0d15, #a6191a, biały)
- `app.js` – mapa, wyszukiwarka i lista sklepów
- `data.js` – lista sklepów ze współrzędnymi (stan listy: 6.10.2026)
- `vendor/leaflet` – biblioteka mapy Leaflet 1.9.4

Podkład mapy: © OpenStreetMap (podpis w rogu mapy jest wymagany).

## Publikacja (GitHub Pages)
Settings → Pages → Source: „Deploy from a branch” → Branch: `main`, folder `/ (root)` → Save.
Po 1–2 minutach strona będzie pod adresem `https://koszebb.github.io/Kosze-Best-buy/`.

## Do uzupełnienia przed udostępnieniem
Dane kontaktowe w stopce (`index.html`, sekcja `footer`) są przykładowe.
